# Deutsch Quest — тренажёр немецкого

Личное приложение: слова, грамматика, чтение, аудирование, письмо — от A0 до B1.
Работает в браузере, прогресс хранится на компьютере. Ничего устанавливать не нужно (только Python).

> Техническая карта проекта (для агента/разработчика) — в **`AGENTS.md`**.

---

## Как запустить (1 клик)

1. Откройте папку проекта.
2. Двойной клик по **`Запустить-сайт.ps1`** → браузер откроется сам на `http://127.0.0.1:8000`.
   - Если сайт уже запущен, скрипт просто откроет новую вкладку.
3. Чтобы остановить — закройте чёрное окно терминала.

> Если так проще — в терминале: `python main.py` (те же действия, без скрипта).

## Версии (бэкапы) — чтобы всегда можно было вернуться

После каждого этапа работы (любой вашей просьбы) автоматически делается **полный снимок проекта**.
Вернуться можно к любой версии — целиком, отдельным файлом или только прогрессом.

**Как понять, где какая версия:**

- На сайте — **кнопка с часиками в шапке** (или адрес `http://127.0.0.1:8000/backups`).
  Список №1, №2, №3… у каждой версии: моя подпись, мой запрос, прогресс/XP в тот момент,
  что изменилось, и кнопки «Вернуть код» / «Вернуть код + прогресс».
- На диске — папка **`backups/`**: `backups/2026-11-22_18-40-12/` = `code/` (вся копия проекта)
  + `info/` (запрос, изменения, статистика, список файлов).
- Снимок вручную — двойной клик по **`Сделать-бэкап.ps1`** (спросит подпись и «что вы хотели»).
- Список в консоли — **`Список-версий.ps1`**.

Кэши (`images/`, `audio_cache/`) в снимок не входят — они тяжёлые и их можно пересоздать
(`python main.py --prefetch-*`), а весь прогресс и код внутри.

## Частые задачи

| Хочу… | Что делать |
|---|---|
| **Добавить слова** | Открой `content/words.txt`, впиши строку `deutsches Wort = перевод` под нужной `# Группой`. Перезапуск не нужен — обновите страницу. |
| **Новая группа слов** | В том же файле добавь строку `# Название группы` и под ней слова. |
| **Урок курса** | `scripts/build_course.py` — меняете текст урока и запускаете `Пересобрать-курс.ps1`. |
| **Новое задание / тест** | Новый файл в `worksheets/` (схема — `worksheets/README.md`). |
| **Текст для «Чтения»** | `web/reading.js` → массив `TEMPLATES`. |
| **Задания «Тренировки»** | `web/train/data-a0.js` … `data-b1.js` — добавьте объект в нужный массив. |
| **Новая мини-игра** | `web/games.js` (CATALOG + функция раунда). |
| **Новая настройка** | `web/settings.js` (контрол) + `web/theme.js` (значение по умолчанию). |
| **Цвета, темы, кнопки** | «Настройки» в самом приложении; в коде — `web/glass.css`. |
| **Проверить, что ничего не сломалось** | `Проверить-сайт.ps1`. |
| **Начать заново / стереть прогресс** | Кнопка в «Статистике»; резервная копия — `content/de_lernen_stats.json`. |
| **Вернуться к старой версии** | Кнопка с часиками в шапке сайта → `/backups` → «Вернуть код» или «Вернуть код + прогресс». |
| **Сделать снимок вручную** | `Сделать-бэкап.ps1` (спросит подпись и что хотели) · список: `Список-версий.ps1`. |

## Что уже умеет

- **Тренажёр**: слова DE↔RU, выбор / ввод / голос, числа и телефоны, повторение по интервалам.
- **Курс**: 24 урока подряд — правило → слова → 8 заданий, следующий урок открывается после прохождения.
- **Тренировка**: 4 уровня (A0–B1) × 4 навыка (слушание, словарь, чтение, письмо).
- **Грамматика**: 9 тренажёров с генерацией заданий (падежи, множественное, времена, предлоги, порядок слов…).
- **Речь**: разговорник, диалоги-симуляции, звуки на слух, «слышу — пишу», повторение за голосом, сказка на ночь.
- **Материалы**: песни и стихи, новости, рецепты, образцы писем, даты и цифры, частицы.
- **Режимы**: спидран на время, «пять минут», быстрый выбор — для дней, когда мало времени.
- **Игры**: 16 мини-игр (спидран, анаграммы, порядок слов, пары, «найди лишнее»…).
- **Задания**: 4 набора — A1 Prüfungstraining (полный тренировочный тест), грамматика A1–A2, 6 времён, тематический словарь.
- **Чтение**: 21 текст A0–A2 с вопросами; клик по слову переводит.
- **Ещё**: таблицы грамматики, диктант, экзамен, «Мои слова», карточки SRS, план дня, дневник, экран «Немецкие звуки», статистика.
- **Настройки**: темы и акценты, размер текста, озвучка, строгость проверки, 10 «фишек» учёбы, таймер и напоминания.
