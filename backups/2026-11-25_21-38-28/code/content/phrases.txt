# Школьные фразы и этикет
Ich verstehe nicht. = Я не понимаю.
Ich weiß es nicht. = Я не знаю.
Können Sie das bitte wiederholen? = Повторите, пожалуйста.
Wie heißt das auf Deutsch? = Как это по-немецки?
Meine Dokumente sind noch beim Schulamt. = Мои документы всё ещё в Шульамте.
Ich warte auf die Bestätigung. = Я жду подтверждения.
Ich lerne Deutsch erst seit Kurzem. = Я учу немецкий совсем недавно.
Entschuldigung. = Извините.
Auf Wiedersehen. = До свидания.
Danke schön. = Большое спасибо.
Bitte schön. = Пожалуйста.
Kannst du mir helfen? = Ты можешь мне помочь?
Ich habe eine Frage. = У меня есть вопрос.
Wie schreibt man das? = Как это пишется?
Was bedeutet das? = Что это значит?
Wo ist die Toilette? = Где туалет?
Darf ich kurz rausgehen? = Можно выйти ненадолго?
Ich brauche einen Stift. = Мне нужна ручка.
Alles klar. = Всё понятно.
Einen Moment, bitte. = Одну минутку, пожалуйста.
Sprechen Sie Englisch? = Вы говорите по-английски?
Ja, genau. = Да, точно.
Kein Problem. = Без проблем.
Hallo, ich heiße Vitali. = Привет, меня зовут Виталий.
Ich bin 17 Jahre alt. = Мне 17 лет.
Ich komme aus der Ukraine. = Я из Украины.
Ich wohne in Heidenheim. = Я живу в Хайденхайме.
Wie viel kostet das? = Сколько это стоит?
Ich hätte gerne einen Kaffee, bitte. = Мне, пожалуйста, кофе.
Wo kann man hier Tickets kaufen? = Где здесь можно купить билеты?
Entschuldigung, wie komme ich zum Bahnhof? = Извините, как мне добраться до вокзала?
Können Sie etwas langsamer sprechen? = Вы не могли бы говорить немного медленнее?
Ich spreche noch nicht so gut Deutsch. = Я ещё не очень хорошо говорю по-немецки.
Das stimmt. = Это верно.
Ich bin gleich wieder da. = Я скоро вернусь.
Was machst du heute Abend? = Что ты делаешь сегодня вечером?
Ich habe keine Ahnung. = Я понятия не имею.
Es tut mir leid. = Мне очень жаль.
Macht nichts. = Ничего страшного.
Einen schönen Tag noch! = Хорошего дня!
Bis später! = До скорого!
Wo ist der nächste Supermarkt? = Где ближайший супермаркет?
Ich suche eine Arbeit. = Я ищу работу.
Wie war dein Tag? = Как прошёл твой день?
Das ist eine gute Idee. = Это хорошая идея.
Kannst du mir das erklären? = Можешь мне это объяснить?
Ich bin müde. = Я устал.
